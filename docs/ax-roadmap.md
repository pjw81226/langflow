# 비개발자를 위한 Langflow AX

## 이번에 만드는 경험

반복 업무와 나만의 처리 노하우를 쉬운 인터뷰로 파악하고, 업무 후보와 그림을 확인한 뒤 실행 가능한 Langflow 초안을 함께 만든다.

- 팀과 담당 업무 → 반복하는 일 또는 노하우 → 보는 자료 → 처리 방법과 확인 기준 → 마지막 결과를 한 번에 하나씩 묻는다.
- 예시 선택, 직접 입력, 잘 모르겠어요, 이전 답 수정으로 답변 부담을 줄인다. 추가 질문은 최대 두 개다.
- 매일 작성하는 보고, 같은 형식의 메일 확인, 자료 비교, 개인의 검토 순서와 판단 기준을 다룬다.
- AI가 제안한 기준은 사용자가 알려준 기준과 구분한다. 설명되지 않은 판단은 사람이 확인한다.
- 첫 버전은 파일과 붙여넣은 내용을 처리한다. 메일 자동 수신, 예약 실행, 사내 시스템 연결은 포함하지 않는다.

## 이후 검토할 기능

| 후보 | 사용자에게 주는 변화 |
| --- | --- |
| 결과를 보며 수정하기 | 결과의 문장이나 표를 선택하고 자연어로 수정한 뒤 전후 결과를 비교한다. |
| 오류 해결 도우미 | 실패한 위치, 쉬운 원인 설명, 수정할 값과 다시 실행하는 경로를 제공한다. |
| 업무 설정 모드 | 노드 대신 자료·처리 기준·결과 형식으로 기존 작업을 조정한다. |
| 엑셀·CSV 연결 도우미 | 시트와 열, 날짜 형식, 누락값을 확인하고 업무 항목과 연결한다. |
| 업무 예제로 품질 비교 | 같은 사례로 변경 전후 결과를 비교하고 누락과 근거를 확인한다. |
| 팀 업무 도구로 공유 | 동료가 파일·조건·실행 버튼만으로 사용할 수 있게 한다. |
| 메일·사내 시스템 연결 | 확인된 처리 방법을 실제 수신·조회·등록과 연결한다. |
| 정해진 시각과 이벤트에 실행 | 매일 보고, 새 메일 도착 같은 시작 조건을 설정한다. |

자동화 범위, 권한, 연결 대상은 각 후속 기능을 구체화할 때 결정한다.
